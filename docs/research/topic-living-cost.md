# 후보 B 「생활비 절약·디지털 생활비 채널 + 앱」 전략 리서치 보고서 (기준일 2026-10-10)

**3줄 요약**
1. **수요는 넓고 확인됩니다.** 국내 유튜브 월 사용시간은 1,136억분입니다. OTT는 국민 89.1%가 쓰고 평균 2.1개를 구독합니다. 알뜰폰은 1,011만 회선이고, 짠테크 채널 김짠부는 구독자 106만입니다. **약점은 앱 결제 전환입니다.** 토스·왓섭과 수많은 무료 구독관리 앱이 핵심 기능을 무료로 줍니다. 게다가 "절약하려는 사람에게 구독료를 받는" 구조라 모순이 있습니다.
2. **무인 자동화에는 후보 중 가장 잘 맞습니다.** 숫자·표·계산 화면이라 절차적으로 만든 시각물로 화면을 채울 수 있습니다. 매주 바뀌는 실제 가격 데이터를 쓰면 영상마다 내용이 달라져 반복 판정을 피하기 쉽습니다. 다만 2026년 7월 YouTube 정책 명확화에 "AI 인물이 금융 주제로 조언하는 콘텐츠"가 수익화 불가 범주로 들어갔습니다. 이 범주와 템플릿 반복을 함께 피해야 합니다.
3. **판단: 조건부 채택을 권합니다(종합 39/60).** 앱은 "가격 인상·결제일 알림 + 통신비 진단"으로 좁히고 월 2,900원·연 24,000원 정도로 시작합니다. 사회복지사 경력을 살려 "감면·지원제도·부모님 고정비" 축으로 경쟁 채널과 차별화합니다.

## 3. 콘텐츠 형식 설계 (무인 자동 제작 기준)

### 3-1. 핵심 원칙: "주간 데이터 이벤트" 기반 제작 (제 설계, 추측)

매주 고정 파이프라인이 **가격 DB의 지난주 대비 변화**를 뽑고, 그 변화가 영상의 원재료가 됩니다. 변화 항목은 다음과 같습니다.
- 구독 서비스 요금 변경
- 알뜰폰 신규 프로모션과 종료
- 유가
- 공공요금 변경
- 감면제도 신청 시기

**근거 데이터 예시**
- 유튜브 프리미엄 한국 요금: 2023년 12월 1만450원에서 1만4,900원으로 인상. https://www.newsis.com/view/NISX20231208_0002551828
- 쿠팡 와우 신규 가입 요금: 2024년 4월 월 4,990원에서 7,890원으로 인상. https://mobile.newsis.com/view/NISX20240418_0002704789

**데이터 원천 (자동 수집 가능성)**
- **오피넷 유가 API:** 무료 제공되며 키를 받아 JSON 또는 XML로 받습니다. https://www.ajunews.com/view/20151130171824139 , https://wikidocs.net/309839
- **알뜰폰허브:** 공공 API는 **미확인**입니다. 수기 큐레이션을 전제로 합니다.
- **모요 등 민간 사이트:** 크롤링은 약관·데이터베이스 권리 위험이 있어 피하기를 권합니다(추측).
- **구독 요금:** 각 사 공지와 보도자료를 운영자가 주 1회 검수하는 반자동 방식을 씁니다.

  - **운영자 본인 목소리로 도입 1~2분과 코멘트**를 넣습니다. 이는 4장의 "사람이 개입한 증거"도 됩니다.

**인스타 카드뉴스**
- 같은 주 데이터 요약 8장: 표지, 변동 3건, 계산 1건, 감면 1건, 행동 유도.

**티스토리 (SEO 롱테일)**
- 구글 검색용 롱테일 주제: "OO 해지 방법 2026", "OO 인상 후 요금", "A 요금제 vs B 요금제 계산".
- 글마다 계산표를 넣습니다.
- **네이버 블로그와 같은 원문을 쓰지 않습니다.** 유사문서로 판정될 위험이 있습니다(업계 통념, 추측). 각도와 문장을 달리 생성합니다.

### 3-3. 시청 가치와 화면 채우기 판단

- **시청 가치 (추측):** 금액·날짜·조건처럼 구체적이고 최신인 숫자가 있으면 TTS라도 가치가 유지됩니다. 반대로 "안 쓰는 구독은 해지하세요" 같은 일반 팁은 가치가 0이고, 정확히 반복 판정에 걸리는 유형입니다.
- **화면:** 전부 절차적으로 생성할 수 있습니다. 차트, 표, 계산기, 영수증, 달력은 HTML/CSS를 Playwright로 프레임 렌더링한 뒤 ffmpeg로 합치면 됩니다. 현재 프로젝트 가상환경(`/home/user/sjcu-python/.venv`)에 이미 playwright, edge-tts, imagehash가 설치되어 있습니다.
- **주의:** edge-tts는 비공식 클라이언트라 상업적 이용 약관이 **미확인**입니다. 수익화 채널이라면 상업 이용 라이선스가 명시된 TTS를 권합니다(추측).

   - AI 도구 사용 자체는 결격 사유가 아닙니다. 다만 결과물에 창작자의 관점과 교육적·오락적 가치가 있어야 합니다.
   - 출처: https://support.google.com/youtube/answer/1311392
2. **스팸 정책:** 자동화 도구나 AI로 조금씩만 바꾼 유사 콘텐츠를 대량으로 만드는 것을 금지합니다. https://support.google.com/youtube/answer/2801973

### 4-3. 회피 설계: 검사기에 넣을 규칙 (임계값은 추측이며 운영하며 보정)

1. **데이터 이벤트 필수:** 가격 DB의 변화, 공식 발표, 사연처럼 고유한 근거 ID가 없는 영상은 발행을 차단합니다. 일반 팁만 있는 영상은 만들지 않습니다.
2. **형식 로테이션:** 7개 계열을 돌리고, 같은 계열을 연속 발행하지 않으며, 계열별로 주 2회 이하로 제한합니다. 색과 레이아웃 변형은 계열마다 여러 벌을 둡니다.
3. **유사도 게이트:** 최근 60편과 비교합니다.
   - 대본 임베딩 코사인 유사도 0.85 이상이면 차단
   - 제목 3-gram 중복률 확인
   - 대표 프레임 지각 해시(pHash) 해밍거리가 기준 미만이면 차단
   - 문장 길이와 구조 분포도 확인
4. **사람이 개입한 증거**
   - 롱폼에는 주 1회 운영자 녹음 코멘트를 넣습니다.
   - 운영자 실제 고지서(개인정보 가림)를 씁니다.
   - 시청자 사연을 반영합니다.
5. **인물 설정 규칙**
   - "재무설계사, 전문가"라고 칭하지 않습니다. 화자는 "계산소 진행 음성"으로 정합니다.
   - 설명란에 "AI 음성 사용"을 고지합니다.
   - 특정 금융상품은 추천하지 않습니다.
   - "개인 상황에 따라 다름" 문구를 넣습니다.
6. **물량 단계 상향 (추측):** 신규 채널은 처음 4주를 주 7편으로 시작합니다. 시청 지속률을 확인한 뒤 주 14편으로 올립니다.
