# 콘텐츠 지침 — 함정노트 공인중개사 (가칭)

모든 스킬(`/weekly-publish`, `/longform`, `/shorts`, `/card-news`, `/tistory-blog`, `/yt-comment-reply`, `/question-bank`)이 원고를 쓰기 전에 읽는 문서다.
근거 자료: `docs/research/round2/judge.md`(주제 선정·설계), `docs/research/facts-originality.md`(반복 판정).

## 1. 채널 정체성

- **누구에게**: 공인중개사 1·2차 수험생, 특히 시간이 부족한 직장인 독학자. 부동산 생활법률이 궁금한 일반인은 넓은 입구로만 쓴다.
- **무엇을**: 시험에서 틀리게 만드는 "함정"(숫자 바꿈, 주체 바꿈, 예외 누락, 기간 혼동, 요건 혼동, 용어 혼동)을 근거 조문과 함께 짧게 깨 준다.
- **약속**: 모든 숫자·요건 옆에 근거를 붙인다 — `[법령명 제○조 제○항 · YYYY.M.D 시행 기준]`, 판례는 `[대법원 사건번호 · YYYY.M.D 선고]`. 근거를 못 붙이는 내용은 다루지 않는다.
- **말투**: 존댓말, 짧은 문장(40자 안팎), 결론 먼저. 수험생을 겁주지 않는다. 과장·유행어·이모지 없음.
- **비공식 고지**: 한국산업인력공단·큐넷과 무관한 비공식 채널·앱이다. 설명란 고지는 자동으로 붙는다.

## 2. 시즌 달력 (기준일 2026-10-10)

| 기간 | 콘텐츠 축 | 앱 안내 |
|---|---|---|
| ~10/31(37회 시험) | 막판 정리: 숫자표·혼동 쌍·기간 타임라인 위주. 새 개념 대신 자주 틀리는 것 | Play 사전등록·대기자 모집("12월 출시") |
| 11/1~12/1 | 시험 직후 과목별 출제 포인트 분석(문항 원문 금지, 포인트만), "38회 0주차" 시작 | 사전등록 |
| 12/2(발표)~12월 | 합격 발표 반응, 38회 학습 계획, 앱 출시 | 앱 설치(무료 20문항) |
| 2027년 1월~ | 4주 순환(아래 4장) | 앱 설치·구독 |
| 매년 8월~시험일 | 막판 60일 패스 시즌 | 60일 패스 |

`channel.yaml` 의 `exam.round`·`exam.next_exam_date` 를 시험이 끝나면 다음 회차로 바꾼다.

## 3. 쇼츠 형식표 (주 14편)

| # | 형식 | 장면 kind (SCENES.md 참고) | 주간 배합 |
|---|---|---|---|
| 1 | 함정 OX | `ox` (+`title` 훅) | 3 |
| 2 | 숫자 빈칸표 | `table_blank` | 2 |
| 3 | 기간 타임라인 | `timeline` → `quiz` | 1 |
| 4 | 절차 흐름도 | `flow`(hidden) | 1 |
| 5 | 순서 맞추기 | `sequence` | 1 |
| 6 | 판례 관계도 | `relations` | 2 |
| 7 | 계산 단계 | `calc` | 1 |
| 8 | 혼동 쌍 비교표 | `compare` | 1 |
| 9 | 개정 전후 비교 | `diff` | 개정이 있는 주에 1번·2번을 대체 |
| 10 | 오답 랭킹 | `ranking` | 앱 출시 후, 앱 데이터가 있는 주에 1번을 대체 |
| 11 | 생활법률 → 시험 연결 | `case` → `bullets` → `ox` | 2 (전체의 30% 이하) |

- 같은 형식은 하루 1편, 주 3편까지. 같은 화면 구성 3편 연속 금지. 각 편 `notes` 첫 줄에 `형식: <이름>`.
- 첫 문장은 질문이나 반전("이 숫자, 10명 중 7명이 틀립니다" 같은 근거 없는 통계는 금지 — 앱 데이터가 있을 때만).
- 쇼츠 끝: 14편 중 절반 이하에서만 "프로필 링크의 앱" 또는 롱폼 연결.

## 4. 롱폼 4주 순환 (25~30분)

ISO 주 번호를 4로 나눈 나머지로 고른다: 1 → A, 2 → B, 3 → C, 0 → D. 시즌 달력의 특집 기간에는 특집이 우선이다.

| 순환 | 주제 | 구성 |
|---|---|---|
| A | 과목별 함정 지문 120 OX (과목 순환) | 범위표 1분 → 10블록 × 12지문(블록마다 요약 비교표) → 많이 틀리는 10지문 재출제 → 앱 덱 안내 |
| B | 숫자·기간 총정리 (공법·세법·중개사법) | 비교표 8장, 타임라인 4개, 빈칸 퀴즈 30개 |
| C | 판례·사례 해부 15선 (민법·민사특별법) | 사례마다 관계도 → 쟁점 → 결론 → 함정 지문 2개 |
| D | 월간 자체 모의 40문항 압축 + 이달 법령 개정 | 문항 20분 → 해설 8분 → 개정 전후 비교 2분 |

- 챕터 5~8개, 한 영상에 장면 kind 5가지 이상.
- 쇼츠 중 3~5편은 그 주 롱폼에서 파생(`source_id`)하되 문장은 새로 쓴다.

## 5. 문제은행이 먼저다

- 퀴즈·OX·빈칸·계산·순서 장면의 정답과 근거는 **검증된 문제은행 문항(status=verified)** 에서만 가져온다. 장면 `params.bank_id` 에 문항 ID 를 적는다.
- 주간 순서: `/question-bank` 절차로 신규 문항 생성 → `python -m studio bank verify` → 통과 문항으로 원고 작성 → 발행 후 `python -m studio bank mark-used`.
- 문항을 만들 때는 법령 원문을 먼저 받아(`python -m studio bank law ...`) 보면서 쓴다. 기억에 의존하지 않는다.
- 판례는 사건번호·선고일이 확인되는 것만 쓴다.

## 6. 검증 가능한 원천

| 원천 | 쓰는 곳 |
|---|---|
| 국가법령정보 공동활용 Open API (law.go.kr DRF) | 법령·시행령·시행규칙 조문, 시행일, 연혁 |
| 같은 API 의 판례 검색 / 대법원 종합법률정보 | 판례 사건번호·선고일·요지 |
| 큐넷 시험 공고 | 시험일, 출제 범위, 기준 법령 시점 |
| 큐넷 가답안·확정답안 | 시험 직후 분석·가채점(정답 번호만, 문항 원문 금지) |
| 국민참여입법센터 입법예고 | 개정 예고 |
| 파이썬 계산(문항 calc 식) | 세액·비율·면적 계산 |

이 표에 없는 원천(블로그, 카페, 강사 교재 문장)은 근거로 쓰지 않는다.

## 7. 반드시 지킬 규칙

1. 숫자·요건 옆 근거 배지(장면 `params.basis`). 시행일 없는 "최신"·"현재 법" 금지.
2. 기출은 "출제 포인트"만("36회에 ○○ 요건이 나왔다"). 문항·보기 원문, 문제지 캡처 금지.
3. 가답안 공개 전 정답 단정 금지, 공개 후 "가답안 기준" 표기.
4. 생활법률은 일반 정보로만. 끝에 "개별 사안은 대한법률구조공단(132)·변호사 상담" 문장.
5. 투자 권유·시세 예측·특정 단지 홍보 금지.
6. 공단 로고·큐넷 화면 흉내 금지. 실존 강사·합격자 이름·얼굴·후기 사용 금지.
7. 금지 표현은 `channel.yaml` 의 `rules.banned_phrases`(검증기가 막는다). 예외가 있는 규정에 "항상"·"절대" 금지.
8. 오류가 확인되면 24시간 안에 정정: 정정 쇼츠 1편, 해당 문항 retired, 블로그 배너. 정정 목록은 `content/comments/*/corrections.md` 와 `content/bank/law_changes/` 에 남는다.

## 8. 카드뉴스 구성 (주 3세트, 8장)

1. 질문형 표지(cover) → 2~5. 표(body + `params.table`)나 흐름(list) → 6. OX 퀴즈(quiz, `choices:["O","X"]`) → 7. 정답과 근거 조문(answer) → 8. 저장 유도·프로필 링크(cta).

## 9. 블로그 구성 (주 3편)

- 유형 순환: 숫자 표 글("건폐율 용적률 표(2026년 ○월 시행령 기준)"), 요건 정리 글("주택임대차 대항력 요건"), 과목 지문 모음("중개사법 함정 지문 OX 30"), 개정 반영 글.
- 구조: 키워드를 앞에 둔 제목 → 상단 요약 표 → 조문 인용(법령 링크) → OX 10문항(정답은 아래 별도 절) → 개정 이력과 기준일 → 자주 묻는 질문 3개.

## 10. 앱 안내 문구 원칙

- 출시 전: "12월에 문제 앱을 엽니다. 프로필 링크에서 사전등록." 출시 후: "오늘 문제 20개는 무료. 틀린 지문은 앱이 다시 내 줍니다."
- 결제·가격은 영상에서 말하지 않는다(스토어 화면이 고지). "합격"을 약속하지 않는다.

## 11. 댓글 응대 규칙

- 답한다: 학습 질문(근거 조문을 들어 짧게), 오류 지적(맞으면 감사 + 정정), 감상(한두 문장, 매번 다른 문장).
- 답하지 않는다: 개별 법률 상담("제 경우에는"), 매물·시세·투자 질문, 스팸·광고·욕설·개인정보, 정치 논쟁.
- 개별 상담 요청에는 한 번만 "개별 사안은 대한법률구조공단(132)이나 변호사 상담을 권합니다"로 답한다.
- 링크를 달지 않는다. 200자 이내.

## 12. 반복 판정 피하기

- 매 편 다른 조문·숫자·사례. 같은 도입 문장·결말 문장을 두 번 쓰지 않는다.
- 형식 배합 상한(3장)을 지킨다. 독창성 검사(`check originality`)의 수정 지시를 그대로 따른다.
- 앱 오답 데이터(오답 랭킹)처럼 이 채널만 가진 데이터를 쓸 수 있으면 우선 쓴다.
